FAQ

常见问题解答

为什么能做到完全免费且无画质、次数限制？
OmniVideoRip 基于开源的 Go + Wails 架构与 yt-dlp / FFmpeg 开源生态构建，所有核心功能对所有人永久免费开放，不设任何 License 付费墙。页面中仅保留少量非侵入式匿名展示位用于覆盖基础发布成本。
「完整离线包 (.zip)」和「单文件绿色版 (.exe)」有什么区别？推荐下载哪个？
绝大多数用户推荐直接下载【完整离线包 (.zip)】，压缩包内已预置通过官方 SHA-256 校验的 yt-dlp.exe 与 ffmpeg.exe，解压即可离线满血使用；如果您希望极简体积（约 13MB），可选择【轻量单文件 (.exe)】，运行后可直接在软件内点击一键下载所需组件。
如果某个主流视频网站改版导致解析失败怎么办？
点击客户端底部的【🔄 更新 yt-dlp】按钮，软件会直接从 yt-dlp 官方 GitHub Release 拉取最新解析规则，通常无需等待客户端重新发版即可快速恢复。如果是自研原生提取站点遇到改版，欢迎附带链接在 GitHub Issues 提交反馈。
下载海外平台需要配置代理吗？软件如何识别代理？
您无需在软件内重复输入端口。只要电脑开启了系统代理（Windows 代理设置）或配置了 Clash / v2ray 等环境变量代理，OmniVideoRip 会在发起请求与调用 yt-dlp 时自动继承同一套代理链路。
遇到 Cloudflare 验证拦截或复杂网页播放页怎么提取下载？
当粘贴受保护页面（如 SupJav）时，软件会弹出 F12 抓流指引弹窗：在浏览器完成验证后按 F12 → 打开 Network（网络）面板 → 过滤 m3u8 → 播放视频并右键复制 .m3u8 地址（或 Copy as cURL），回到软件点【读取剪贴板 .m3u8 并下载】即可自动带 Referer 满速拉取。

准备好体验无限制的本地视频提取了吗？

免注册、无会员订阅，下载解压即可在 Windows 10/11 上极速运行。
